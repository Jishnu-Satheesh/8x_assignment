# Phase 1 asset provenance

The app uses eight source photographs from Unsplash as visual inspiration. The collection's titles and creative direction are original editorial notes, not claims about camera metadata, model output, ownership, or the photographer's process. Preview dialogs link to the exact source image. No photographer name is invented.

The downloaded files are served locally, including responsive variants generated by Next.js. Runtime page rendering makes no third-party image or font requests. Downloads total **867,196 bytes** for the eight photographs and two font files, before Next.js responsive optimization.

Image license: [Unsplash License](https://unsplash.com/license). The app makes no claim that pictured people or brands endorse the workspace. These photographs illustrate discovery styles; they are not reusable approved generation references in Phase 1.

Manrope and Space Grotesk were downloaded as Latin WOFF2 variable fonts from Google Fonts. Their SIL Open Font License files are bundled beside them in `public/fonts/`. The actual font URLs, license URLs, file sizes, and SHA-256 checksums for all ten assets are recorded in [asset-manifest.json](asset-manifest.json).

The reproducible download utility is `scripts/prepare_phase1_assets.py`. It fetches only the documented public assets and does not use credentials. The approved design reference under `docs/design/` remains a design artifact; its external prototype CDN dependencies are not application dependencies.
